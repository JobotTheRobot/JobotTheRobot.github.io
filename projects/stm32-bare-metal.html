STM32 Bare Metal

Hands-on STM32 firmware experiments focused on understanding how microcontrollers work close to the hardware.

StatusExperiments / ongoing learning
RoleFirmware Developer

Technical details

My experiments include basic GPIO output, such as driving LEDs on an STM32F103 Nucleo board. I’ve also used STM32 microcontrollers in larger firmware projects.

Design decisions

I use small, focused exercises to understand MCU behavior and how code interacts with hardware, keeping each experiment easier to debug.

Challenges & results

The visible result so far is a basic hardware demonstration. I’ll document source code and tests as I organize the experiments.
