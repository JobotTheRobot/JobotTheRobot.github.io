# JobotTheRobot.github.io

Static personal engineering portfolio for GitHub Pages.

## Structure

- `index.html` - landing page and featured projects
- `projects.html` - project gallery
- `projects/` - individual project case studies
- `about.html` - experience, education, and links
- `resume.html` - embedded resume viewer
- `CONTENT_GUIDE.md` - recommended project and page content
- `style.css` - shared responsive styles

The site has no build step or external dependencies. Replace the marked media and link placeholders as project documentation becomes available.
